# PROJECT — Marketing OS

Internal founder-operated Marketing OS built by customizing Hermes rather than rebuilding an agent runtime. MVP combines Market Radar, Content Engine and Conversation Intake across Saudi Arabia, UAE, Qatar, Syria, Bahrain, Oman, Jordan, Lebanon and Turkey with manual country weighting and separate B2B vs legitimate technical/academic funnels.

Service priority: AI services/projects → technical/academic technology/programming/computing services → general software systems/websites.

Acquisition: dynamic regional discovery via SearXNG + source registry. Page acquisition uses direct public API/HTTP when sufficient and Crawl4AI as the primary rich crawling/rendering/extraction framework. Evidence/provenance is mandatory. Clients Hunter is a donor codebase for selective migration only.

Product runtime: Hermes base, Antigravity preferred reasoning, Gemini API fallback if necessary/allowed, no Codex/OpenAI/ChatGPT runtime. Operator surfaces: CLI + Telegram. External actions initially require human approval. Zero incremental spend remains governing.
